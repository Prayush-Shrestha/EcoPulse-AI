# Scripts

Repeatable operational scripts belong here. Phase 1 documents its commands in
[development.md](../docs/development.md) instead of adding wrappers before they
are needed.

Future candidates, added only when a real workflow requires them:

- dataset download and checksum verification
- local database reset
- model training and evaluation
- frontend/backend smoke checks

Scripts must be documented, safe to re-run, and must not contain secrets.
